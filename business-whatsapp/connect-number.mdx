The **Account** page shows the WhatsApp number COD King sends from and its connection to Meta. Open it from the **Manage account** link on [Business Brand WhatsApp](/business-whatsapp/overview).

<Frame>
  ![Account page with the Refresh and Add number buttons, the number card and the Default badge](/images/wa-04-account.png "The arrows point to the Verified badges, the Add number button, the Label Edit link and Show technical details")
</Frame>

## Your numbers

The page is headed "WhatsApp numbers". The **default** number is used for any notification that is not routed to a specific number. To send a notification or a campaign from a different number, choose that number when you create the automation.

| Setting | What it does |
| --- | --- |
| **Refresh** | Reloads the number list and its status from WhatsApp. |
| **Add number** | Connects another WhatsApp Business number. |
| **Default** and **Verified** badges | **Default** marks the number used when nothing else is chosen. **Verified** means Meta has verified the business name. |
| **Sending from** | The phone number messages go out from. |
| **Verified name** | The business name customers see on WhatsApp. |
| **Label** | A private name that helps you tell numbers apart. Click **Edit** to change it. |
| **Show technical details** | Expands the connection details from Meta. |

## Send a test message

<Frame>
  ![Send a test message box with the Recipient field, the Template drop-down and the Manage templates and automations button](/images/wa-05-test-message.png "The arrows point to the Recipient field, the Template drop-down and the Manage templates & automations button")
</Frame>

**Send a test message** sends one template message from this number so you can check it works. Only approved templates are listed.

<Steps>
  <Step title="Enter the recipient">
    Type the full number with the country code and no plus sign, for example `919999988888`.
  </Step>
  <Step title="Choose a template">
    Pick an approved template from the drop-down. Click **Refresh from WhatsApp** if a template you just approved is missing.
  </Step>
  <Step title="Click Send test">
    The message goes to that number straight away.
  </Step>
</Steps>

<Warning>
  A test message is a real WhatsApp message and counts toward your WhatsApp usage. Send it only to a number you control.
</Warning>

## Manage templates and disconnect

**Manage templates & automations** opens the [Templates](/business-whatsapp/templates) page. **Disconnect** removes the number from COD King. Do not use it on a live store unless you plan to connect a number again.

<Note>
  Messages go out from your own number, so Meta's WhatsApp Business rules apply to it. Customers must be able to reply STOP, which the pre-made templates include.
</Note>
