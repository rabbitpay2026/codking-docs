# Troubleshooting

This section will contain verified solutions for common COD King setup and configuration issues.

## Before contacting support

When reporting an issue, keep relevant store context, screenshots, and the affected COD King feature available. Avoid sharing passwords, API keys, access tokens, or other sensitive credentials in screenshots.
