Having an issue with COD King? This guide covers common configuration, messaging, order, and integration issues and provides practical steps to help you resolve them quickly.

Before troubleshooting, make sure your Shopify store is connected correctly and that the latest COD King settings have been saved.

## Quick Troubleshooting Checklist

Before checking a specific feature, verify the following:

1. Make sure COD King is installed and active on your Shopify store.
2. Confirm that the required feature is enabled in COD King.
3. Save your configuration after making changes.
4. Check that the required credentials, phone numbers, API keys, or other configuration values are correct.
5. Test the feature again after saving the configuration.
6. If the issue involves SMS or WhatsApp, verify that the selected messaging provider is active and properly configured.
7. If the issue continues, contact the COD King support team.

## OTP Verification Issues

If customers are not receiving OTP messages or OTP verification is not working correctly, check the following:

- Confirm that OTP verification is enabled in COD King.
- Verify that the customer's phone number is valid.
- Make sure the phone number includes the correct country code where required.
- Check that your configured SMS or WhatsApp provider is active.
- If you are using a Local SMS Gateway, verify that the provider credentials are correct.
- Save the configuration before testing again.

For detailed OTP configuration, see [Setting Up OTP Verification on Shopify](/setting-otp-verification-on-shopify).

## SMS or WhatsApp Messages Are Not Being Delivered

If SMS or WhatsApp notifications are not being delivered, first determine which messaging service is being used.

### Check Your Messaging Configuration

Verify that:

- The messaging feature is enabled.
- The selected provider is correct.
- The provider credentials are valid.
- The sender ID or sender name is correctly configured where required.
- The provider account has sufficient balance or credit.
- The recipient phone number is valid and includes the correct country code.
- Your latest configuration changes have been saved.

For general SMS and WhatsApp configuration, see [Setting Up SMS and WhatsApp on Shopify](/setting-sms-and-whatsapp-in-shopify).

## COD Fees Are Not Being Applied

If COD charges are not appearing as expected, check the following:

- Confirm that COD Fees are enabled.
- Verify that the configured fee amount or rules are correct.
- Check whether the fee conditions apply to the current order.
- Confirm that the customer is selecting Cash on Delivery at checkout.
- Save the configuration and test again.

For detailed configuration instructions, see [Setting COD Fees in Shopify](/setting-cod-fees-in-shopify).

## Partial Payment Is Not Working

If customers cannot make a partial payment on COD orders, check the following:

- Confirm that Partial Payment is enabled.
- Verify the configured payment amount or percentage.
- Check that your payment gateway is configured correctly.
- Confirm that the payment option is available for the current order.
- Make sure the configuration has been saved.

For detailed instructions, see [Setting Up Partial Payment](/partial-payment/overview).

## Prepaid Discount Is Not Appearing

If the prepaid discount is not being displayed to customers:

- Confirm that the Prepaid Discount feature is enabled.
- Check the configured discount amount or percentage.
- Verify that the current order meets the configured conditions.
- Confirm that the prepaid payment method is available.
- Save the configuration and test the checkout again.

For detailed instructions, see [Setting Up Prepaid Discount](/setting-prepaid-discount-in-shopify).

## COD to Prepaid Conversion Is Not Working

If customers are not seeing the option to convert their COD order to prepaid, check the following:

- Confirm that COD to Prepaid is enabled.
- Verify the configured discount rules.
- Check that the order qualifies for the conversion.
- Confirm that the payment gateway used for prepaid payments is configured correctly.
- Verify that the customer is accessing the supported order or checkout flow.
- Save the configuration before testing again.

For detailed instructions, see [Setting Up COD to Prepaid Conversion](/setting-cod-to-prepaid-conversion-in-shopify).

## Customers Are Not Receiving Order Notifications

If order-related SMS or WhatsApp notifications are not being received:

1. Confirm that the notification feature is enabled.
2. Verify that the customer's phone number is correct.
3. Check your SMS or WhatsApp provider configuration.
4. Verify your messaging account balance or available credits.
5. Check whether the selected provider supports the destination country or number.
6. Save the configuration and test the notification again.

If you are using a Local SMS Gateway, open the corresponding provider guide from the Local SMS Gateway section.

## Local SMS Gateway Test Fails

If the **Test Your Integration** option fails, check the following:

- Make sure the operator credentials are saved before testing.
- Verify every credential entered in COD King.
- Confirm that the Sender ID, Sender Name, or Masking matches the value approved by the provider.
- Use a valid recipient phone number with the country code.
- Check the provider account balance or SMS credit.
- Confirm that the provider account is active.
- Check whether the provider has any restrictions on the destination number.

After correcting the configuration, save the operator settings and send another test SMS.

## SMS Provider Credentials Are Invalid

If COD King reports invalid operator credentials:

- Recheck the API Key.
- Recheck the API Secret, API Token, Password, or other provider-specific credential.
- Make sure there are no extra spaces before or after the credentials.
- Confirm that the credentials belong to the correct provider account.
- Generate new credentials from the provider if the existing credentials have expired or been revoked.
- Save the updated credentials in COD King before testing again.

Refer to your provider's setup guide for the exact credential requirements.

## Sender ID or Sender Name Is Not Working

If messages fail because of the Sender ID, Sender Name, or Masking:

- Confirm that the sender name has been approved by the provider.
- Enter the sender name exactly as registered.
- Check whether the provider treats uppercase and lowercase characters differently.
- Confirm that the sender is available for the destination country.
- Check whether the provider requires sender registration before API usage.

Do not enter an unapproved sender name unless the provider explicitly allows it.

## Phone Number Format Issues

Always enter phone numbers using a valid format supported by your messaging provider.

When required, use the international format with the country code.

For example:

`+919876543210`

The exact supported format can vary between SMS providers, so check the provider-specific documentation if a message fails because of the phone number format.

## Changes Are Not Taking Effect

If a setting appears to have no effect after changing it:

1. Confirm that the setting was actually saved.
2. Refresh the COD King page.
3. Reopen the relevant configuration section.
4. Verify that the new value is still present.
5. Test the feature again using a new order or supported test option.
6. If the issue continues, contact support.

## When to Contact Support

Contact COD King support if:

- You have verified the configuration but the issue continues.
- A feature is not behaving as expected.
- A valid provider configuration continues to fail.
- You need help identifying the correct setting.
- You experience an issue that cannot be resolved using this guide.

## Before Contacting Support

To help the support team resolve your issue faster, include:

- Your Shopify store URL.
- The COD King feature you are having trouble with.
- A short description of the issue.
- The steps you took before the issue occurred.
- The provider name if the issue involves SMS or WhatsApp.
- Any relevant error message.
- Whether the issue affects all customers or only specific orders.

> **Security:** Never send your API keys, API secrets, passwords, authentication tokens, or other private credentials in a support request.

## You're All Set

Most COD King issues can be resolved by checking the feature configuration, saving the latest settings, and verifying the associated messaging or payment provider.

If the issue persists after completing the relevant checks, contact the COD King support team with the required details so the issue can be investigated efficiently.
