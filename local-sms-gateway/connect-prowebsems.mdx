ProWebSms, formerly known as smshare, provides SMS messaging services for businesses and supports SMS delivery through Android devices and SMS gateways. You can connect your ProWebSms account to COD King to send SMS notifications to customers from your Shopify store.

ProWebSms supports SMS delivery in multiple countries, including Turkey and other international destinations. For more information, visit the [official ProWebSms website](https://www.prowebsms.com/).

## Step 1: Create a ProWebSms Account

If you don't already have a ProWebSms account, create one from the [official ProWebSms registration page](https://www.prowebsms.com/register).

After creating your account, log in to the [ProWebSms dashboard](https://www.prowebsms.com/dashboard/composer).

Your ProWebSms **Login ID** and **Password** are the credentials you use to access your account.

## Step 2: Get Your Login ID and Password

Your **Login ID** and **Password** are the credentials associated with your ProWebSms account.

Use the same credentials that you use to sign in to the ProWebSms dashboard.

In COD King:

- **Login ID:** Enter your ProWebSms account login.
- **Password:** Enter your ProWebSms account password.

For more information, refer to the [official ProWebSms login page](https://www.prowebsms.com/dashboard/composer).

## Step 3: Generate Your Access Token

ProWebSms requires an access token for API requests.

According to the official API documentation, an access token is generated using the account login and password together with the ProWebSms developer/API key.

The API authentication endpoint is:

`/api/v2/access-token`

The access-token request uses:

- Login
- Password
- API Key
- Application name

For more information, see the [official ProWebSms API documentation](https://www.prowebsms.com/doc/index.html).

Once the required credentials are available, use the **Generate access token** option in COD King.

1. Enter your **Login ID**.
2. Enter your **Password**.
3. Click **Generate access token**.
4. COD King will generate the **Access Token**.
5. Confirm that the Access Token is populated in the field.

Keep your access token secure and do not share it publicly.

## Step 4: Get Your Gateway UUID

The **Gateway UUID** identifies the specific SMS gateway or device that ProWebSms will use for sending messages.

According to ProWebSms's official documentation, you can find the gateway/device UUID from your ProWebSms dashboard.

1. Log in to your [ProWebSms dashboard](https://www.prowebsms.com/dashboard/composer).
2. Open your device or gateway list.
3. Select the gateway or device you want to use.
4. Open its details.
5. Copy the **Gateway UUID**.

ProWebSms's official guide explains that the gateway UUID and access token are available from the gateway/device details and can be used when configuring API-based SMS sending. For more information, see the [official ProWebSms gateway configuration guide](https://www.prowebsms.com/blog/opencart/use-smartphone-or-gateway-created-in-your-prowebsms-dashboard/index.html).

The **Gateway UUID field in COD King is optional**. If you do not need to specify a particular gateway, you can leave this field empty.

## Step 5: Connect ProWebSms to COD King

1. Open your **Shopify Admin**.
2. Go to **Apps** and open **COD King**.
3. Navigate to **Settings**.
4. Select **Local SMS gateway**.
5. Select **ProWebSms (Smshare) (Global)** from the **Network Provider** dropdown.
6. Enter the following details:
   - **Login ID:** Enter your ProWebSms account login.
   - **Password:** Enter your ProWebSms account password.
   - **Access Token:** Enter the access token generated by COD King.
   - **Gateway UUID (optional):** Enter the UUID of the ProWebSms gateway or device you want to use.
7. Save your settings.

## Step 6: Send a Test SMS

After saving your ProWebSms configuration:

1. Scroll to the **Test Your Integration** section.
2. Enter a valid phone number in the **Phone Number** field.
3. Click **Send Test SMS**.
4. Check the recipient phone for the test message.

If you specified a Gateway UUID, COD King will use that gateway for the integration.

## Troubleshooting

If the test SMS is not delivered:

- Verify that the **Login ID** is correct.
- Verify that the **Password** is correct.
- Generate a new **Access Token** if the existing token is invalid or expired.
- Make sure the Gateway UUID belongs to an active ProWebSms gateway or device.
- If you are not using a specific gateway, leave the **Gateway UUID** field empty.
- Make sure your ProWebSms account has the required SMS credits or sending setup.
- Verify that the test phone number is entered correctly.

ProWebSms also provides a [pricing page](https://www.prowebsms.com/pricing) with information about API charges, SMS credits, Android sending, and other gateway options.

If the issue continues, contact [ProWebSms support](https://www.prowebsms.com/contact).
